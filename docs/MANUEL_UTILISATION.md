## 1. Introduction

### 1.1 Qu'est-ce qu'Archimag ?

**Archimag** est une plateforme complète de gestion électronique de documents et d'informations. Elle permet à votre entreprise de :

✅ **Stocker** tous vos documents de manière centralisée et sécurisée  
✅ **Organiser** vos fichiers avec une structure logique et intuitive  
✅ **Partager** des documents avec vos collègues en toute confiance  
✅ **Automatiser** vos processus documentaires  
✅ **Rechercher** rapidement n'importe quel document  
✅ **Tracer** qui accède à quoi et quand  

### 1.2 Profils Utilisateurs

**Vous êtes...**

| Profil | Accès | Niveau de Complexité |
|--------|-------|----------------------|
| 👤 **Utilisateur Standard** | Consultation, création, partage | Facile |

## 3. Gestion des Documents

### 3.1 Créer un Dossier

#### Méthode 1 : Via le Menu

```
1. Cliquez sur "📁 MES DOSSIERS" dans le menu gauche
2. Cliquez sur le bouton "+ NOUVEAU DOSSIER"
3. Entrez le nom du dossier : "Factures 2026"
4. (Optionnel) Sélectionnez une couleur
5. Cliquez sur "CRÉER"
```

#### Résultat Attendu
```
✅ Dossier "Factures 2026" créé avec succès !
```

### 3.2 Télécharger des Documents

#### Méthode 1 : Glisser-Déposer

```
1. Ouvrez le dossier destination
2. Glissez les fichiers de votre ordinateur
   vers la zone de dépôt
3. Les fichiers s'envoient automatiquement
4. Attendez la barre de progression
```

#### Méthode 2 : Clic Classique

```
1. Ouvrez le dossier destination
2. Cliquez sur "+ AJOUTER DOCUMENTS"
3. Sélectionnez les fichiers à uploader
4. Cliquez sur "OUVRIR"
5. Attendez le chargement (barre de progression)
```

#### Types de Fichiers Acceptés

✅ **Documents** : PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx)  
✅ **Images** : PNG, JPG, GIF, SVG  
✅ **Autres** : ZIP, 7Z, RAR  
✅ **Vidéos** : MP4, MOV, AVI (max 2 GB)  

❌ **Non acceptés** : .exe, .bat, .sh (fichiers exécutables)

#### Taille Limite

| Type | Limite |
|------|--------|
| Fichier simple | 10 GB |
| Upload par lot | 50 GB (total) |
| Stockage total | Selon votre plan |

### 3.3 Éditer les Métadonnées d'un Document

Les **métadonnées** sont des informations sur le document (auteur, date, classification, etc.).

#### Modifier les Métadonnées

```
1. Cliquez sur le document (pour l'ouvrir)
2. Cliquez sur l'onglet "DÉTAILS" en haut
3. Modifiez les champs :
   • Titre : [Rapport Financier Q2]
   • Description : [Budget et prévisions]
   • Département : [Finances]
   • Classification : [Confidentiel]
   • Tags : [Budget, Finances, 2026]
4. Cliquez sur "ENREGISTRER"
```

#### Champs Disponibles

| Champ | Type | Exemple |
|-------|------|----------|
| Titre | Texte | Rapport Financier Q2 |
| Description | Texte long | Synthèse des résultats Q2 |
| Auteur | Sélection | Jean Dupont |
| Département | Sélection | Finances |
| Classification | Sélection | Confidentiel / Interne / Public |
| Tags | Multi-sélection | Budget, 2026, Urgent |
| Date de révision | Date | 15/07/2026 |

### 3.4 Télécharger un Document

```
1. Cliquez sur le document
2. Cliquez sur le bouton "⬇️ TÉLÉCHARGER" (coin supérieur droit)
3. Le fichier se télécharge sur votre ordinateur
```

### 3.5 Prévisualiser un Document

```
1. Cliquez sur le document
2. L'aperçu s'affiche automatiquement
3. Utilisez les commandes :
   • 🔍 Zoom avant / arrière
   • ⬅️ ➡️ Pages précédente / suivante (si PDF multi-pages)
   • 🖨️ Imprimer
   • ⬇️ Télécharger
```

### 3.6 Supprimer un Document

```
1. Cliquez avec le bouton droit sur le document
2. Sélectionnez "Supprimer" ou cliquez sur 🗑️
3. Confirmez la suppression
4. Le document est déplacé à la "Corbeille"
```

⚠️ **Attention** : Les documents supprimés sont conservés 30 jours avant destruction définitive.

### 3.7 Historique de Versions

Chaque fois que vous modifiez un document, une nouvelle version est créée automatiquement.

#### Consulter les Versions

```
1. Ouvrez le document
2. Cliquez sur l'onglet "VERSIONS"
3. Vous voyez la liste de toutes les versions :
   • Version 3 (actuelle) - 15/07/2026 10:30 - Jean D.
   • Version 2 - 14/07/2026 14:15 - Marie P.
   • Version 1 - 10/07/2026 09:00 - Jean D.
4. Cliquez sur une version pour la visualiser
5. Cliquez sur "RESTAURER" pour revenir à cette version
```

## 4. Gestion des Autorisations

### 4.1 Partager un Document

#### Partage Simple

```
1. Ouvrez le document
2. Cliquez sur "PARTAGER" (icône 👥)
3. Entrez l'email du collègue : marie.pelletier@entreprise.com
4. Sélectionnez le niveau d'accès :
   ○ 👁️ CONSULTATION (lecture seule)
   ○ ✏️ ÉDITION (modifier)
   ○ 🔐 ADMINISTRATION (modifier + gérer permissions)
5. Cliquez sur "ENVOYER L'INVITATION"
```

#### Niveaux d'Accès

| Niveau | Description | Actions Possibles |
|--------|-------------|-------------------|
| 👁️ **Consultation** | Lecture seule | Visualiser, télécharger, commenter |
| ✏️ **Édition** | Modifier le document | Tout + modifier, renommer, supprimer |
| 🔐 **Administration** | Gestion complète | Tout + gérer les permissions |

#### Partage Avancé

```
1. Ouvrez le document
2. Cliquez sur "⚙️ PARTAGE AVANCÉ"
3. Options disponibles :
   • Partage avec un groupe (ex: "Équipe Finances")
   • Lien de partage public (génère un URL)
   • Accès temporaire (expiration à date fixe)
   • Notification à la personne
4. Configurez et cliquez sur "APPLIQUER"
```

### 4.2 Gérer les Permissions d'un Dossier

```
1. Cliquez sur le dossier

## 5. Workflows et Automatisation

### 5.1 Qu'est-ce qu'un Workflow ?

Un **workflow** est un processus automatisé qui exécute des actions sur vos documents. Par exemple :

```
📄 Un document arrive → 📧 Notification → ✅ Approbation → 📁 Archivage
```

### 5.2 Créer un Workflow Simple

#### Cas d'Usage : Approbation de Factures

```
1. Allez à ⚙️ PARAMÈTRES > WORKFLOWS
2. Cliquez sur "+ NOUVEAU WORKFLOW"
3. Nommez-le : "Approbation Factures"

ÉTAPE 1 : DÉCLENCHEUR
   Sélectionnez : "Quand un document est uploladé"
   Filtres : Dossier = "Factures en attente"

ÉTAPE 2 : ACTION
   Sélectionnez : "Notifier un utilisateur"
   À qui : "Marie Pelletier"
   Message : "Veuillez approuver la facture {NOM_DOCUMENT}"

ÉTAPE 3 : APPROBATION
   Sélectionnez : "Attendre une approbation"
   De : Marie Pelletier
   Timeout : 5 jours

ÉTAPE 4 : RÉSULTAT
   Si approuvée → Déplacer vers "Factures Approuvées"
   Si rejetée → Déplacer vers "Factures Rejetées"

4. Cliquez sur "ENREGISTRER ET ACTIVER"
```

#### Aperçu Visuel du Workflow

```
                    ┌─────────────────┐
                    │ Document uploadé│
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Notification à  │
                    │ Marie Pelletier │
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    ▼                 ▼
            ┌──────────────┐  ┌──────────────┐
            │ APPROUVÉE ✅  │  │ REJETÉE ❌    │
            └────┬─────────┘  └────┬─────────┘
                 │                 │
                 ▼                 ▼
         ┌──────────────┐  ┌──────────────┐
         │ Dossier      │  │ Dossier      │
         │ "Approuvée"  │  │ "Rejetée"    │
         └──────────────┘  └──────────────┘
```

### 5.3 Workflows Prédéfinis

Archimag propose des templates de workflows prêts à l'emploi :

| Nom | Description | Secteur |

| 📋 Approbation Simple | 1 approbateur, délai configurable | Tous |
| 🔄 Approbations en Cascade | Plusieurs approbateurs en séquence | RH, Finance |
| 👥 Approbations Parallèles | Plusieurs approbateurs simultanément | Comités |
| 📧 Routage Automatique | Classement basé sur critères | Tous |

```

2. Tapez votre requête : "facture juillet"
3. Appuyez sur Entrée
4. Les résultats s'affichent
```

### 6.2 Recherche Avancée

```
1. Cliquez sur 🔍 RECHERCHE AVANCÉE
2. Remplissez les critères :
   • Mots-clés : [Rapport]
   • Auteur : [Jean Dupont] (dropdown)
   • Date de création : Du [01/01/2026] au [31/07/2026]
   • Type de fichier : [PDF, Excel]

   • Département : [Finances]
   • Statut : [Approuvé]

#### Opérateurs Booléens Avancés

| Opérateur | Exemple | Résultat |
|-----------|---------|----------|

| OU (\|) | rapport \| analyse | Documents contenant RAPPORT OU analyse |
| NON (-) | facture - annulée | Factures SAUF les annulées |
| Guillemets ("") | "rapport mensuel" | Phrase exacte |
| Wildcard (*) | rap* | Commence par "rap" |

## 9. FAQ et Dépannage

### 9.1 Problèmes de Connexion

❓ **Je n'arrive pas à me connecter**

✅ Solutions :
1. Vérifiez votre connexion Internet
2. Vérifiez que CAPS LOCK est désactivé
3. Cliquez sur "Mot de passe oublié ?"
4. Vérifiez votre dossier spam pour l'email de réinitialisation
5. Contactez l'administrateur si le problème persiste

---

❓ **Je reçois "Authentification échouée après 2FA"**

✅ Solutions :
1. Assurez-vous que l'heure de votre téléphone est correcte
2. Générez un nouveau code
3. Essayez à nouveau dans 30 secondes
4. Si vous ne pouvez pas recevoir le SMS, utilisez l'app Authenticator

---

### 9.2 Problèmes d'Upload

❓ **Le fichier ne s'envoie pas**

✅ Solutions :
1. Vérifiez la taille du fichier (max 10 GB)
2. Vérifiez le type de fichier (pas .exe, .bat)
3. Vérifiez que vous avez les permissions d'écriture
4. Essayez un autre navigateur
5. Videz le cache du navigateur (Ctrl+Shift+Delete)

---

❓ **"Espace disque insuffisant" lors de l'upload**

✅ Solutions :
1. Allez à ⚙️ PARAMÈTRES > STOCKAGE
2. Voyez votre quota utilisé
3. Supprimez des documents anciens ou inutiles
4. Contactez l'administrateur pour augmenter votre quota

---

### 9.3 Problèmes de Partage

❓ **Je ne peux pas accéder à un document partagé**

✅ Solutions :
1. Vérifiez que vous avez reçu l'invitation
2. Acceptez l'invitation dans l'email
3. Vérifiez votre email junk/spam
4. Demandez à la personne qui a partagé de revérifier les permissions

---

❓ **"Vous n'avez pas les permissions pour cette action"**

✅ Solutions :
1. Vous n'avez probablement que l'accès "Consultation"
2. Demandez à l'administrateur d'augmenter vos permissions
3. Vérifiez auprès de votre manager ou du créateur du dossier

---

### 9.4 Recherche et Filtres

❓ **La recherche ne trouve rien, mais le document existe**

✅ Solutions :
1. L'indexation prend quelques minutes après upload
2. Attendez 5 minutes et réessayez
3. Essayez une recherche plus générale (moins de mots-clés)
4. Vérifiez que vous avez les permissions de lecture

---

❓ **Trop de résultats de recherche**

✅ Solutions :
1. Affinez votre recherche (plus de critères)
2. Utilisez les filtres (type, date, auteur)
3. Utilisez des guillemets pour une phrase exacte : "rapport mensuel"
4. Essayez les opérateurs booléens (AND, OR, NOT)

---

### 9.5 Workflows

❓ **Mon workflow ne s'exécute pas**

✅ Solutions :
1. Vérifiez que le workflow est "Actif" (pas suspendu)
2. Vérifiez que le déclencheur est correct
3. Vérifiez les filtres du déclencheur
4. Attendez quelques secondes après l'action
5. Consultez les logs du workflow (⚙️ > Workflows > Historique)
